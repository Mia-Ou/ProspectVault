第一次打开

1
点左侧 📤 导入资料，上传你的简历（PDF / Word / TXT 都行）
2
点 ＋ 新增岗位，把招聘 JD 粘贴进去，填好公司和岗位
3
重复步骤 2，把所有目标岗位加进去

每天打开

  • 概览页 → 看今天有什么到期、哪些该推进
  • 投递总表 → 更新状态（网申中 → 笔试 → 面试 → Offer）
  • 流程看板 → 拖拽卡片或点箭头推进
  • 面试完 → 点进公司研究页，在「面试记录」里写复盘

🚀 快捷导入岗位（Bookmarklet）

从招聘网站一键抓取 JD，不用再手动复制粘贴。

第一步：安装到书签栏（只需一次）

1
按 Ctrl + Shift + B 显示浏览器书签栏
2
打开工作台 → 点左侧 📤 导入资料 → 切到「招聘信息」标签
3
看到蓝色区域里的 「📋 抓JD」 按钮 → 按住它拖到书签栏，松手
4
完成！书签栏多了一个叫"📋 抓JD"的书签

第二步：以后每次添加岗位

①
在招聘网站（Boss直聘/拉勾/猎聘/公司官网等）打开岗位详情页
②
点书签栏的 「📋 抓JD」
③
页面弹出"✅ 已复制 JD 到剪贴板"
④
切回工作台 → 文本框里 Ctrl+V → 点「🤖 AI 智能解析」
⚠️ 支持大多数招聘网站，但部分网站（如需登录的）可能无法抓取。失败时直接复制页面文字粘贴即可。

五个页面干什么的

页面看什么怎么用
概览全局数据大数、到期提醒、快捷入口
投递总表一个岗位一行搜索、筛选、编辑、导出 CSV
流程看板一个岗位一张卡片按阶段看进度，拖拽推进
公司研究一家公司一份业务分析 + 面试记录 + 拿 offer 可能性
发现AI 推荐AI 联网搜索的高匹配岗位

💡 一家公司投了 3 个岗位 → 总表/看板里出现 3 行，研究页只有 1 份。

🎯 拿 offer 可能性

每家公司旁边会显示一个百分比和标签：

标签含义建议
🟢 有希望（≥40%）你的背景和公司门槛较匹配重点投入，好好准备
🟡 冲一冲（20-39%）有机会但差距存在可以投，但别只押这一家
🔴 困难（＜20%）院校/实习背景低于往年录用者投了不亏，但别抱太大期望

评估基于你的简历背景 + 公司行业地位 + 岗位匹配度综合计算。点进去可以看到详细分析（你的优势、差距在哪）。

🤖 AI 功能（可选）

不配 AI 也能用全部功能，只是「自动解析」和「竞争力评估」要手动填。

配了之后可以偷懒：

  • 上传简历 → 自动提取院校、实习、技能
  • 粘贴 JD → 自动识别公司、岗位、城市、截止日期，一键加入投递表
  • 粘贴面经 → 自动整理成结构化面试记录
  • 自动算拿 offer 可能性

怎么配

1
点左侧 🤖 AI
2
选一个预设（推荐 DeepSeek 或 Kimi，便宜好用）
3
去对应官网申请 API Key，粘贴进去
4
点「测试连接」，绿色就 OK
🔒 隐私：你的 Key 只存在这台电脑的浏览器里，不会上传。AI 请求直接从你浏览器发到服务商，没有中间人。
⚠️ 如果测试连接报 CORS 错误，换硅基流动或智谱试试，这两家支持最好。

💾 数据会丢吗

会。因为数据存在浏览器里，清浏览器缓存 = 数据全没。

解决办法：定期点左侧 ☁️ 同步备份：

操作干嘛的
导出 JSON下载一个备份文件，存在 U 盘 / 网盘
生成同步码复制一段文字，粘到另一台电脑的同页面里恢复

建议每周导一次，或者每次重要更新后导一次。

两个 HTML 文件有什么区别

文件数据用途
index.html空的，0 条记录分享给别人、部署到网站
秋招工作台.html含你的真实数据你自己本地用
📤 给别人用就发 index.html，里面没有任何个人信息。

⚠️ 已知限制

  • 扫描件 PDF（图片型）无法提取文字，需手动粘贴
  • .doc 旧格式不支持，另存为 .docx
  • AI 评估仅供参考，模型可能编造细节，请自行判断
  • 多设备不实时同步，靠手动备份搬运
