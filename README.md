# ProspectVault · 把求职当 deal 做

**一个文件管完秋招。** 投了哪些、到哪一步了、哪家有戏——全在这里。

---

## 30 秒上手

```
下载 index.html → 双击打开 → 上传简历 → 完事
```

不需要安装任何东西，不需要注册账号，断网也能用。

## 日常怎么用

### 第一次打开

1. 点左侧 **📤 导入资料**，上传你的简历（PDF / Word / TXT 都行）
2. 点 **＋ 新增岗位**，把招聘 JD 粘贴进去，填好公司和岗位
3. 重复步骤 2，把所有目标岗位加进去

### 每天打开

- **概览页**看今天有什么到期、哪些该推进
- **投递总表**更新状态（网申中 → 笔试 → 面试 → Offer）
- **流程看板**拖拽卡片或点箭头推进
- 面试完点进公司研究页，在「面试记录」里写复盘

### 一个岗位投出去了

在总表里找到它，把状态改成「已投递」即可。后续有进展继续改。

## 五个页面干什么的

| 页面 | 粒度 | 干什么 |
|---|---|---|
| **概览** | 全局 | 看大数、到期提醒、快捷入口 |
| **投递总表** | 一个岗位一行 | 搜索、筛选、编辑、导出 CSV |
| **流程看板** | 一个岗位一张卡片 | 按阶段看进度，拖拽推进 |
| **公司研究** | 一家公司一份 | 业务分析 + 面试记录 + **拿 offer 可能性** |
| **发现** | — | AI 推荐的高匹配岗位（可选功能） |

> **注意**：一家公司投了 3 个岗位，总表/看板里会出现 3 行，但研究页只有 1 份。

## 拿 offer 可能性

每家公司旁边会显示一个百分比和标签：

| 标签 | 含义 | 建议 |
|---|---|---|
| 🟢 有希望（≥40%） | 你的背景和公司门槛较匹配 | 重点投入，好好准备 |
| 🟡 冲一冲（20-39%） | 有机会但差距存在 | 可以投，但不要只押这一家 |
| 🔴 困难（<20%） | 院校/实习背景低于往年录用者 | 投了也不亏，但别抱太大期望 |

评估基于你的简历背景 + 公司行业地位 + 岗位匹配度综合计算。**点进去可以看到详细分析**（你的优势、差距在哪）。

## AI 功能（可选）

**不配 AI 也能用全部功能**，只是「自动解析」和「竞争力评估」要手动填。

配了之后可以偷懒：
- 上传简历 → 自动提取院校、实习、技能
- 粘贴 JD → 自动识别公司、岗位、城市、截止日期，一键加入投递表
- 粘贴面经 → 自动整理成结构化面试记录
- 自动算拿 offer 可能性

### 怎么配

1. 点左侧 **🤖 AI**
2. 选一个预设（推荐 **DeepSeek** 或 **Kimi**，便宜好用）
3. 去对应官网申请 API Key，粘贴进去
4. 点「测试连接」，绿色就 OK

**隐私**：你的 Key 只存在这台电脑的浏览器里，不会上传到任何地方。AI 请求直接从你浏览器发到服务商，没有中间人。

> ⚠️ 如果测试连接报 CORS 错误，换 **硅基流动** 或 **智谱** 试试，这两家 CORS 支持最好。

## 快捷导入岗位（Bookmarklet）

**从招聘网站一键抓取 JD，不用再手动复制粘贴。**

### 第一步：安装到书签栏（只需一次）

1. 打开工作台 → 点左侧 **📤 导入资料** → 切到「招聘信息」标签
2. 看到一个蓝色区域里有 **「📋 抓JD」** 按钮
3. **按住按钮，拖到浏览器书签栏**，松手
4. 完成！书签栏多了一个叫"📋 抓JD"的书签

> 💡 看不到书签栏？按 **Ctrl + Shift + B**（Windows）或 **Cmd + Shift + B**（Mac）显示出来。

### 第二步：每次添加岗位

1. 在招聘网站（Boss直聘/拉勾/猎聘/公司官网等）打开岗位详情页
2. 点书签栏的 **「📋 抓JD」**
3. 页面顶部弹出"✅ 已复制 JD 到剪贴板"
4. 切回工作台 → 在文本框里 **Ctrl + V** → 点「🤖 AI 智能解析」

搞定。比手动选文字复制快很多。

> ⚠️ 支持大多数招聘网站，但部分网站（如某些需要登录的）可能无法抓取。如果失败，直接复制页面上的 JD 文字粘贴即可。

## 数据会丢吗

**会。** 因为数据存在浏览器里，清浏览器缓存 = 数据全没。

**解决办法**：定期点左侧 **☁️ 同步备份**：

| 操作 | 干嘛的 |
|---|---|
| 导出 JSON | 下载一个备份文件，存在 U 盘/网盘 |
| 生成同步码 | 复制一段文字，粘到另一台电脑的同页面里恢复 |

建议每周导一次，或者每次重要更新后导一次。

## 两个 HTML 文件有什么区别

| 文件 | 数据 | 用途 |
|---|---|---|
| `index.html` | **空的**，0 条记录 | 分享给别人、部署到网站 |
| `秋招工作台.html` | 含你的真实数据 | 你自己本地用（构建产物文件名沿用，逻辑名 ProspectVault） |

**给别人用就发 `index.html`**，里面没有任何个人信息。

## 高级：本地服务器（可选）

如果你想要：
- 数据自动写磁盘（不怕清浏览器缓存）
- 手机和电脑看同一份数据

仓库里有个 `server.py`，运行它：

```bash
python _app/server.py
```

然后打开 `http://localhost:8765`。不需要可以不运行。

## 开发者

```bash
# 构建（需要先填 jobs.json，或留空产空白工作台）
python _app/build.py

# 从「净收入计算」文本生成结构化月度预算（薪资卡片可视化的数据源）
python _app/build_budget.py                 # → jobs.json（个人数据）
python _app/build_budget.py jobs.example.json  # → 开源示例数据

# 跑测试
npm i jsdom
node _app/smoke_test.js index.html
node _app/oss_test.js
node _app/budget_test.js
```

- 源码在 `_app/template.html`，改完跑 `build.py` 重新构建
- 改了数据结构，记得同步两处示例：`jobs.example.json` 和 `template.html` 里的 `sampleData()`（公开版「载入示例数据」用的是后者）
- 数据格式见 `jobs.example.json`
- 欢迎提 Issue 和 PR，详见 [CONTRIBUTING.md](CONTRIBUTING.md)
