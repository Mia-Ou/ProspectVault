# 秋招工作台

> 一个**完全离线、隐私优先**的秋招 / 求职跟踪工具。
> 单个 HTML 文件，双击即用，不需要安装、不需要注册、不连任何服务器 —— **所有数据只保存在你自己的浏览器里**。

上传简历、招聘信息、面试资料，它帮你把"投了什么、走到哪一步、哪家有戏"理清楚。

---

## 它能做什么

| 功能 | 说明 |
| --- | --- |
| **投递总表** | 一个岗位一行；搜索 / 筛选 / 排序；点行直接编辑 |
| **流程看板** | 未投递 → 网申 → 筛选 → 笔试 → 面试 → Offer / 已拒，拖拽卡片推进 |
| **公司研究** | 每家公司一份研究卡：业务画像、岗位拆解、薪资与代价、风险雷达、**竞争力评估**、面试记录 |
| **拿 offer 可能性** | 结合你的背景画像与公司录用门槛，给出 0–100 的竞争力评分与「有希望 / 冲一冲 / 困难 / 几乎不可能」分档 |
| **面试记录** | 按轮次记录时间、结果、自评、过程与复盘 |
| **资料导入** | 上传简历 / JD / 面经（PDF · Word · TXT · Markdown），可选 AI 自动结构化 |
| **备份与跨设备** | 导出 JSON 备份文件，或生成一段"同步码"文本，粘到另一台设备即可继续 |
| **CSV 导出** | 一键导出投递总表，用 Excel 打开 |

**数据粒度约定**：投递总表 / 看板 / 概览是**岗位级**（一家公司的多个岗位分开展示），公司研究是**公司级**（一家公司一份研究）。

## 快速开始

### 方式一：直接用（推荐）

1. 下载仓库根目录的 **`index.html`**
2. 双击用浏览器打开
3. 按页面上的三步引导走：上传简历 → 导入招聘信息 → 开始跟踪

没有任何依赖，断网也能用（AI 解析功能需要联网）。

### 方式二：部署到 GitHub Pages

Fork 本仓库 → Settings → Pages → 选择 `main` 分支根目录 → 打开 `https://<用户名>.github.io/<仓库名>/`。

### 方式三：自己构建（想内嵌自己的初始数据）

```bash
cp jobs.example.json jobs.json     # 复制示例数据结构
# 编辑 jobs.json，填成你自己的公司和简历
python _app/build.py
```

产物：

| 文件 | 用途 |
| --- | --- |
| `index.html` / `webapp/index.html` | **公开版**，不含任何数据，可安全分享 |
| `秋招工作台.html` | **个人完整版**，内嵌 `jobs.json` 的全部数据（已在 `.gitignore` 中，不会误提交） |

> 没有 `jobs.json` 也能构建 —— 会产出一份空白工作台，数据由使用者在浏览器里录入。

## AI 功能（完全可选）

**不配置 AI，全部跟踪功能照常使用**，只是「自动解析」和「竞争力评估」需要你手动填。

配置后可以做：

- 📄 **简历 → 背景画像**：提取院校、实习、技能、亮点、短板
- 📢 **JD → 岗位记录**：自动识别公司、岗位、城市、截止日期、硬性要求，一键加入投递表
- 🎯 **竞争力评估**：结合你的背景与公司录用门槛，给出拿 offer 概率与改进建议
- 🎤 **面经 → 面试记录**：整理成结构化记录，归入对应公司

### 怎么配

点右上角 **🤖 AI** → 选服务商预设 → 填 API Key → 点「测试连接」。

支持任何 **OpenAI 兼容**的 `/chat/completions` 接口，已内置预设：DeepSeek、通义千问、智谱 GLM、Kimi、硅基流动、OpenAI，也可以填自定义地址（如本地 Ollama：`http://localhost:11434/v1`）。

### 关于 AI 的隐私

- API Key **只存在你这台设备的浏览器 localStorage 里**，不会写进导出文件、同步码或备份
- 请求**从你的浏览器直接发给你填写的服务商**，本工具没有任何中转服务器
- 简历 / JD 文本只在你点击「AI 解析」时才会发送

> ⚠️ 浏览器直连可能受服务商 CORS 策略限制。若报 CORS 错误，请换用支持跨域的服务商，或填你自己的反向代理地址。

## 隐私设计

| 项目 | 做法 |
| --- | --- |
| 数据存储 | 浏览器 `localStorage`，键名 `qf_workbench_v2` |
| 网络请求 | 默认**零请求**；只有你主动配置了 AI 才会请求你指定的服务商 |
| 公开版产物的内容 | `records: []`，不含任何真实数据 |
| 个人数据 | `jobs.json` 及 `秋招工作台.html` 已在 `.gitignore` 中 |

**注意**：清除浏览器数据会一并清掉工作台内容。请定期用「☁️ 同步备份」下载 JSON 备份。

## 数据结构

以 **公司** 为单位组织，同公司的多个岗位合并成一条记录：

```jsonc
{
  "metadata": { "dataGen": "gen1", "created": "2026-09-01" },
  "resume":   { "headline": "一句话定位", "raw": "简历原文", "profile": { ... } },
  "records": [
    {
      "id": "job_xxx", "company": "公司名", "industry": "行业", "location": "城市",
      "positions": [ { "title": "岗位", "dept": "部门", "match": 82, "status": "面试", "deadline": "2026-10-31" } ],
      "interviewStages": [ { "round": "一面", "date": "2026-09-10", "result": "通过", "notes": "…" } ],
      "research": { "competitionAnalysis": { "score": 55, "label": "冲一冲", "reason": "…" }, "report": {} }
    }
  ]
}
```

完整字段见 [`jobs.example.json`](jobs.example.json)。

> **dataGen 机制**：做结构性数据变更（改主键、合并拆分记录、大改字段）时请 bump `metadata.dataGen`。
> 浏览器发现种子的 dataGen 与本地不一致时，会以权威数据重置，避免新旧数据叠加错乱。

## 开发

```bash
# 构建
python _app/build.py

# 测试（需要 jsdom）
NODE_PATH=<你的 node_modules 路径> node _app/smoke_test.js index.html
NODE_PATH=<你的 node_modules 路径> node _app/oss_test.js
```

- `_app/template.html` —— 唯一的应用源码（HTML + CSS + JS 全在一起）
- `_app/build.py` —— 把模板里的 `__SEED_JSON__` 占位符替换成数据，产出三份 HTML
- `_app/smoke_test.js` —— 常规冒烟（视图粒度、交互接线）
- `_app/oss_test.js` —— 开源版专项（引导流程、AI 配置、上传中心、免 AI 降级、隐私）

改代码一律改 `template.html`，然后重新构建。

## 已知限制

- PDF 解析依赖 CDN 加载 pdf.js，**图片型 / 扫描件 PDF 无法提取文字**（需先 OCR，或直接粘贴文本）
- `.doc` 旧格式浏览器无法解析，请另存为 `.docx` 或 `.pdf`
- AI 评估质量取决于你填的背景信息详略，且模型可能编造公司细节 —— 结论请自行判断
- 多设备之间不是实时同步，靠"同步码 / 备份文件"手动搬运
